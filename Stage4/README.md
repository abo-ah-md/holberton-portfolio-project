## 🛠️ Tech Stack

- React + Vite
- Supabase
- React Router DOM

## ⚙️ Setup

### 1. Clone & Install
```bash
git clone https://github.com/abo-ah-md/holberton-portfolio-project.git
cd bookpass
npm install
```

### 2. Environment Variables

Create `.env` file in root directory:
```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

Get credentials from [Supabase](https://supabase.com):
- Project Settings → API → Copy URL & anon key

### 3. Run
```bash
npm run dev
```

Open `http://localhost:5173`
