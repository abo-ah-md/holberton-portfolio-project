# User Stories - Bookpass Marketplace

## MUST HAVE

1. As a new student, I want to register with email and university affiliation, so that I can access the marketplace.

2. As a seller, I want to create a book listing with title, author, ISBN, condition, price, and photos, so that buyers can find my textbook.

3. As a buyer, I want to search and filter books by title, author, ISBN, course, university, and price range, so that I can quickly find what I need.

## SHOULD HAVE

1. As a seller, I want to mark a book as sold, so that buyers know it's no longer available.

2. As a buyer, I want to save books to a wishlist, so that I can keep track of books I'm interested in.

3. As a buyer, I want to send messages to sellers and view conversations in an inbox, so that I can inquire about books and negotiate prices.

## COULD HAVE

1. As a buyer, I want to request a specific book not currently available, so that sellers can notify me when they have it.

2. As a seller, I want to view analytics about my listings (views, clicks, conversions), so that I can optimize my sales strategy.

3. As a buyer, I want integrated payment processing through a secure gateway, so that transactions are convenient and verified.
