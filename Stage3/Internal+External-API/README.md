# Internal + External API

This document outlines the APIs used in the BookPass project, including both internal APIs developed for the application and external third-party APIs integrated to enhance functionality.

## Internal APIs
The internal APIs are designed to handle core functionalities of the BookPass platform, including user management, book listings, and transaction processing. These APIs are built using RESTful principles and are hosted on our backend server.

Use the internal-API.yaml with Swagger online editor to view the full documentation.

Link: https://editor.swagger.io
file: [Internal-API.yaml](./Internal-API.yaml)
